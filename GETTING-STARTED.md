# AI Now Bench 7: first run and useful comparisons

## Run a Windows PC benchmark

1. Get the Windows x64 installer from the [official download page](https://ainowbench.com/download.html), which lists the current build and checksum.
2. Check the [system requirements](https://ainowbench.com/instructions.html#system-requirements), install, and save your work before testing.
3. Close demanding background applications. Keep the power mode, cooling and driver configuration consistent when comparing repeat runs.
4. Choose the full **Standard / Recommended** benchmark. Review the sharing checkbox first: uncheck it for local-only reports.
5. Let the suite finish, then review the PDF and TXT reports. If a shared run is accepted, keep its Result ID for the [Results Center](https://results.aicreatenow.com/).

## Read the result

Start with the six category scores, then inspect the raw measurements and status of individual tests. Use the [scoring methodology](https://ainowbench.com/methodology.html) to interpret the overall rating. A score out of 100 is a calibrated rating; it is not a hardware-utilization percentage or a population percentile.

For a meaningful before-and-after comparison, record the change being tested and use the same benchmark build and similar operating conditions. Treat a skipped or failed row separately from a successfully measured result.

## Common questions

**Do I need an Advanced Pro key?** No. The full Standard benchmark and local reports are free. Advanced Pro adds optional diagnostics and stress testing.

**Must I publish my results?** No. Review the sharing setting before each run. Keep full technical TXT reports private; they can include Windows names, paths and diagnostics.

**Where do I find help for a failed test?** Review the report's status and [official instructions](https://ainowbench.com/instructions.html). Send the application version, relevant hardware, error and Result ID to [support](SUPPORT.md).
