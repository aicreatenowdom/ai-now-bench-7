# AI Now Bench 7 support

Contact [info@aicreatenow.com](mailto:info@aicreatenow.com) for benchmark help, licensing, privacy or result-removal requests.

Include the application version, Windows version, relevant hardware, what you expected, what happened and steps to reproduce the problem. Include a Result ID if relevant.

[Instructions](https://ainowbench.com/instructions.html) · [Scoring methodology](https://ainowbench.com/methodology.html) · [Release notes](https://ainowbench.com/AINowBench-7.0-Changelog.txt)

Send full technical reports through private email support. Reports can contain Windows user/computer names, local paths and diagnostics; do not attach them to a public issue. Remove passwords, tokens, license keys and unrelated personal information from anything you share.

Application downloads are available from the [official download page](https://ainowbench.com/download.html). GitHub's Code / Download ZIP contains this repository's documentation and artwork, not the Windows application.
